<h1 align="center">GSeek</h1>
<p align="center"><b>Find your files by what you remember.</b><br>
Private, multilingual file search for GNOME, powered by EmbeddingGemma 2.</p>

GSeek brings semantic search to the Activities overview. It uses GNOME LocalSearch
to discover your files and a native GTK4/libadwaita application to manage indexing.

The first implementation is in progress on the `feat/native-search` branch.
Installation instructions and screenshots will accompany the working build.
